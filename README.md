# EquityPanel

Audit clinical risk models for performance gaps across demographic groups
(race, sex, age band): subgroup metrics with confidence intervals, threshold
analysis, and eGFR race-coefficient reclassification.

> Work in progress: milestone 1 (scaffold + data loaders).

## Install (development)

    python -m venv .venv
    source .venv/Scripts/activate   # Windows Git Bash
    pip install -e ".[dev]"
    pytest
